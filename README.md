# MeoArch package control plane

This repository is the source of truth for MeoArch package recipes, release
manifests, channel packages and publication checks.  Component source stays in
its owning repository; this repository never vendors component trees.

Repository layout:

- `packages/`: Arch package recipes and package-owned pacman configuration.
- `manifests/`: immutable stable release-train inputs and package catalog.
- `scripts/`: manifest, overlay and publication validation helpers.
- `tests/`: host-independent release-contract tests.
- `docs/`: operator documentation.  It intentionally contains no private key
  material or storage credentials.

The public keyring payload is deliberately not generated by CI.  A release
cannot be published until `packages/meo-keyring/files/` contains the exported,
reviewed public keyring files described in `docs/KEY_MANAGEMENT.md`.
